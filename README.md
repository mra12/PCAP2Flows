# PCAP2Flows
PCAP2Flows is a Docker-based tool for converting packet capture (PCAP)
files into network-flow CSV datasets using Argus, NTLFlowLyzer, and
Zeek-flowmeter.

## Download

The complete tested PCAP2Flows v1.0 distribution is archived on Zenodo.

**[Download PCAP2Flows v1.0 from Zenodo](https://doi.org/10.5281/zenodo.22116697)**

The Zenodo release contains the pre-built Docker environment,
PCAP2Flows source code, configuration files, and supporting files
required to reproduce the software environment described in the
PCAP2Flows SoftwareX article.

## Source code

The PCAP2Flows-specific Python source code is available in this
repository for inspection and development. The complete executable
distribution is provided through Zenodo.
